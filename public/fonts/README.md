# Bundled PDF fonts

These WOFF files are application-facing copies of Noto Sans and Noto Sans
Devanagari from `@fontsource` version 5.3.0. They are licensed under SIL Open
Font License 1.1; the corresponding full license files are kept here as
`OFL-Noto-Sans.txt` and `OFL-Noto-Sans-Devanagari.txt`.

The PDF renderer reads these local files at runtime. Do not replace them with
fonts that are installed only on a developer machine or fetched during a
private document render.
