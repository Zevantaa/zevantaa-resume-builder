# ATS assessment provenance

The indicative ATS score is calculated from the reviewed canonical profile and the deterministic Global ATS document model. It is not a third-party ATS score, certification, selection prediction, or guarantee.

Algorithm `zevantaa-indicative-ats-v1` uses eight fixed dimensions totaling 100 points. The visible benchmark of 90 is a comparison target only; it is never a minimum, floor, override, or generation gate. Sparse but valid profiles retain their genuinely calculated lower score.

When document generation starts for a stable career revision, the service records the exact score, benchmark, dimension scores, maximums and non-sensitive measurable reasons. The database verifies that dimension scores sum to the supplied total, maximums sum to 100, the revision is current, and repeated calculations for the same revision are identical. Snapshots contain no candidate prose or document bytes and are service-role-only.

The client ATS page shows a before-and-after comparison only when:

- two recorded snapshots use the same algorithm version;
- the newest snapshot matches the current canonical career revision; and
- both scores are genuine persisted calculations.

The comparison lists only dimensions whose points increased and explains the current measurable reason, such as distinct skill count, supplied summary length, complete employment entries, or explicit date consistency. If no criterion increased, the interface says so rather than claiming an improvement.
