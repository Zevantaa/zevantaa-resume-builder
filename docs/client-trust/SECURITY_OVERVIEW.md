# Zevantaa Resume Builder — security overview

This describes engineering controls and known limitations for due diligence, not a certification or production security attestation. Supabase Auth provides email/password sessions; server-side role checks distinguish administrator and client access. Administrators provision clients; public signup is disabled in the intended configuration and must be confirmed live. Privileged account creation and updates run on trusted server paths. Candidate uploads and generated files are designed for private Storage, with access checked against account/profile linkage before server-side delivery.

Code includes input validation, file-type/size checks, private download headers, production rate-limit hooks, security audit events, regression tests, lint/build and dependency auditing. Browser/public keys are separated from server-only keys. HTTPS is required for deployment configuration; provider-managed encryption at rest and HTTPS in transit are relied on, not custom end-to-end encryption. Audit insertion is best effort and not tamper-proof. Live RLS/Storage, recovery, CSP, rate-limit key and backup/restore evidence remain open SEC-01 gates; production release remains NO-GO until verified. No ISO/SOC certification or independent penetration-test result is claimed.
